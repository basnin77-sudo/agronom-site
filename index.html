03 / ХОРОШО ЗНАТЬ

Остались
вопросы?

Самое важное перед первым знакомством с приложением.

Для кого создано приложение? +

Для садоводов, дачников и любителей комнатных растений — от начинающих до опытных.

Работает ли без интернета? +

Локальные записи и встроенные справочные материалы доступны без сети. Свежая погода и анализ фотографии требуют подключения.

Можно ли определить болезнь по фотографии? +

Приложение помогает предположить возможные причины. Это не окончательный диагноз: сверяйте рекомендации с состоянием растения и инструкциями к препаратам.

Какая версия приложения актуальна? +

В исходном коде проекта указана версия 0.9.0+12. Доступна сборка build-36 на GitHub Releases. Проверяйте версию и подпись APK перед установкой.

Есть ли версия для iPhone? +

На текущем этапе приложение разрабатывается для Android. iOS-версия не опубликована.
